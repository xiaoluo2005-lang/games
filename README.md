# Hen’s Egg Garden 🐔🥚

A small chicken-and-egg game.

## How to play

- Press **Start game**.
- Hens run around and lay eggs.
- Click eggs to collect them.
- Collect **101 eggs** before any egg hatches to win.
- If an egg hatches first, it’s game over.
